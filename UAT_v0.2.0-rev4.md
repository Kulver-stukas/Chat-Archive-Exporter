# rev.4 acceptance checks

Use a backed-up Vault and the same unpacked extension directory as rev.3 hotfix 2. No migration is required. Both participating writers should use a compatible version; do not clear storage.

1. Chats: open an existing workspace with manually and automatically saved chats. Confirm both show archived when current; change a chat and verify update pending until saved. ChatGPT-only archived chats with no local copy are Not archived. Test all filters and selection counts.
2. Switch account and Vault. No archive badge from previous binding. With an unavailable index or permission, show unknown currency rather than a false negative. Cached list remains useful; current revision is relative to latest available provider list.
3. Start manual export, background sync and Library update in test Vault. Compare Markdown/ZIP, originals, index paths, settings, enrollment date, queue, inventory and activity history. Confirm no unexpected API scans or Memory exports.
4. Two browsers: verify passive Chats/Files reads during a writer claim, writer contention, own abandoned-claim recovery and explicit foreign/legacy cleanup. Rev.4 does not allow parallel writers against the shared global index.
5. Check a profile with existing archived/renamed/project/GPT chats, Library inventory, downloads and configuration. No migration or new permissions should be requested. Verify widget state and existing UI navigation.
