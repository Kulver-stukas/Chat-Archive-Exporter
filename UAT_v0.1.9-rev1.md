# UAT — Chat Archive Exporter v0.1.9 rev.1

Дата: 2026-11-25. Проверять отдельно в Chrome и Edge; записать браузер и его версию. Результаты ниже не заполнены заранее.

Обновить расширение в прежней папке, нажать Reload и обновить вкладку ChatGPT. Проверить v0.1.9 rev.1 в Settings.

## 1. Общие настройки и кнопка

- [ ] В popup и panel видны Download MD со стрелкой и Complete conversation.
- [ ] Первый запуск: All и Complete conversation включены.
- [ ] Стрелка раскрывает Question / Answers / Thinking, разделитель, Uploaded files / Generated files.
- [ ] Отключение отдельной категории переводит All в смешанное состояние.
- [ ] Изменение checkbox в popup отражается в panel и в другом экземпляре расширения; сохраняется после закрытия и перезапуска браузера.
- [ ] All off блокирует экспорт пустого набора. Escape закрывает меню; Tab/Space работают с контролами.
- [ ] На странице не появилась кнопка экспорта. Необязательный monitor widget работает по прежней настройке.

## 2. Полный разговор, выбранные категории

Использовать разговор с несколькими парами вопросов и ответов и доступным Thinking.

- [ ] Отключить Uploaded files и Generated files, оставить Complete conversation. Download MD выдаёт .md без открытия селектора.
- [ ] Question only: отсутствуют тексты ответов и Thinking.
- [ ] Answers only: отсутствуют тексты вопросов и Thinking; соседние ответы остаются раздельными.
- [ ] Thinking only: присутствует только доступный Thinking, без текста вопросов/ответов.
- [ ] All: содержимое и порядок соответствуют текущей ветке разговора.
- [ ] Код, LaTeX и доступные ссылки на источники сохранились корректно.

## 3. Выбор сообщений

- [ ] Отключить Complete conversation и нажать основную часть Download MD в popup: открывается существующая side panel, загрузка файла ещё не запускается.
- [ ] В списке раздельные вопросы и логические ответы; ответ с Thinking выбирается одной строкой.
- [ ] All / Questions / Answers / None / Invert изменяют выделение и счётчик.
- [ ] Выбрать один вопрос и один ответ: Markdown содержит только их и включённые категории.
- [ ] При смене чата, вкладки или workspace старое выделение сбрасывается и не экспортируется в новом контексте.
- [ ] При изменении ветки/редактировании ответа после открытия селектора устаревшая выборка не выдаётся; после Refresh можно выбрать заново.
- [ ] Ошибка загрузки сообщений не запускает пустой или другой разговор.

## 4. Оригиналы файлов

Использовать небольшую загрузку пользователя, доступный generated file и generated image. Проверять известные оригинальные байты, например SHA-256 локальных копий.

- [ ] При включённых файлах получен ZIP с Markdown и originals; ссылки в Markdown открывают соответствующие файлы внутри распакованного пакета.
- [ ] Uploaded files only: текст выключен, сохраняются только оригиналы выбранных сообщений пользователя.
- [ ] Generated files only: загруженные ранее пользователем файлы не объявляются generated даже при упоминании в ответе.
- [ ] Файл из невыбранного сообщения не присутствует в ZIP.
- [ ] Повтор одного file ID создаёт одну бинарную копию; разные файлы с одинаковым именем не перезаписываются.
- [ ] Недоступный или истёкший sandbox-файл отмечен unavailable в Markdown/отчёте; остальные файлы обработаны.
- [ ] ZIP не содержит _selection_snapshot.json, credential headers, временные signed URL из resolver или тексты невыбранных сообщений.
- [ ] Файлы выше лимита 25 MiB отмечены как не загруженные; успешное сохранение для них не заявлено.

## 5. Фоновое задание и доставка

- [ ] После принятия задания закрытие панели не прекращает обработку.
- [ ] Изменение общих категорий после принятия задания не меняет уже принятую выборку.
- [ ] Stop прекращает новые запросы; подготовленная часть имеет явную partial-отметку.
- [ ] Отмена браузерного Save не оставляет глобальный busy lock; следующий экспорт можно запустить.
- [ ] При доступном тестовом сценарии перезапуск worker не скачивает повторно уже подготовленный оригинал и не выдаёт повреждённый ZIP.
- [ ] При потере исходной вкладки/workspace задание ждёт исходный контекст и не обращается к другому аккаунту.

## 6. Регрессия существующих сценариев

- [ ] Save to Vault сохраняет полный разговор при любых настройках Download MD.
- [ ] Существующий Vault, проверка локальных изменений и Library/Project Sources работают как в v0.1.8.
- [ ] Открытие Files/Library не запускает автоматический полный rescan.
- [ ] Panel шириной 320 px пригодна к работе, без горизонтальной прокрутки; проверить светлую и тёмную темы.
