# Chat Archive Exporter — UI/UX TODO после v0.1.9

Дата: 2026-11-25.

Основание: четыре пользовательских скриншота и локальный архив ChatGPT Exporter v6.13.2. Поведение референса изучено для сопоставления функций; его реализация не переносится в CAE.

## Текущий этап: выборочный экспорт

- Общие категории: All / Question / Answers / Thinking / Uploaded files / Generated files.
- All включает пять категорий. При частичном наборе показывает смешанное состояние.
- Complete conversation отдельно определяет охват сообщений. При выключенном флаге открывается селектор в существующей side panel.
- Настройки категорий и Complete conversation общие для popup и panel во всех вкладках. Выделение конкретных сообщений привязано к workspace, conversation и branch.
- Файлы относятся к выбранным сообщениям. Допускается экспорт файлов без текста вопроса или ответа.
- Thinking означает доступные данные соответствующего сообщения; скрытые рассуждения не восстанавливаются.

## P1 — следующий этап UI/UX

- [ ] **Выбор отдельных вложений и изображений:** при наличии доступных ссылок отображать дочерние строки файлов с именами под промптом или ответом, независимо от наличия текста. Добавить индивидуальные чекбоксы и согласовать их с выбором родительского сообщения и категориями Uploaded/Generated. Обновлять ожидаемый формат MD/ZIP, счётчики и статус доступности по реально выбранным оригиналам. Не подставлять имена и происхождение без достаточных метаданных.
- [ ] **Настройки метаданных Markdown:** независимо включать заголовок разговора, ссылку на разговор, временные метки сообщений и название модели. Использовать только полученные метаданные; неизвестную модель не подставлять. Изменение относится к ручному экспорту, без автоматической смены формата существующего Vault.
- [ ] **Web Search Sources и Deep Research References:** независимые настройки сохранения доступных источников. По умолчанию сохранять ссылки и библиографические сведения; не превращать файл с отключёнными ссылками в документ с недостоверными маркерами цитирования.
- [ ] **Предпросмотр состава экспорта:** число вопросов, ответов, блоков Thinking и файлов, фактическая доступность оригиналов, объём при наличии метаданных. Недоступный файл должен иметь явный статус.
- [ ] **Навигация селектора:** поиск по тексту, переход к выбранному сообщению внутри селектора и удобное раскрытие длинных сообщений. Сохранить клавиатурное управление, видимый фокус, счётчик выбора и узкую ширину панели.

## P2 — дополнительные настройки ручного экспорта

- [ ] **Шаблон имени файла:** `{title}`, `{date}`, `{time}`, `{custom}` с живым примером и проверкой допустимого имени. Для начала достаточно нескольких пресетов и пользовательского префикса. Стабильные пути Vault не менять этим параметром.
- [ ] **Подписи ролей:** настраиваемые Prompt / Response в выходном документе. Реальные роли и message IDs сохраняются независимо от подписей.
- [ ] **Дата и время:** ISO/локальный формат, 12/24 часа, явный часовой пояс. Машинные временные метки архива сохраняются в UTC.
- [ ] **Copy Markdown:** отдельная команда с теми же категориями и выбранными сообщениями. Для бинарных файлов нужен явный статус: буфер обмена содержит текст, а сохранённые оригиналы требуют пакета экспорта.
- [ ] **Автозакрытие селектора:** только после подтверждённого успешного сохранения. Отмена браузерного Save и ошибка доставки сохраняют выделение.
- [ ] **Именованные наборы настроек:** например, полный разговор, ответы без Thinking, только файлы. Отдельные presets оправданы после проверки базового меню на реальных сценариях.

## P3 — по подтверждённой потребности

- [ ] **Имя и email в документе:** только явно заданные пользователем значения, выключено по умолчанию. Не извлекать их дополнительно ради оформления экспорта.
- [ ] **Дополнительные форматы:** оценивать отдельно после стабилизации Markdown; PDF-специфичные настройки референса не включаются в текущий объём.

## Не переносить из референса

- Show/Hide Export Buttons: кнопка экспорта на странице провайдера не устанавливается.
- Список всех перестановок имени файла: компактный шаблон и предварительный просмотр проще для настройки.
- Дублирование браузерной настройки папки загрузки в расширении без отдельной пользовательской потребности.
- Зависимость экспорта Thinking от раскрытия DOM-блока на странице: фильтр применяется к доступным данным полученного разговора.

## Технические условия для оригиналов файлов

Загрузка требует точного соответствия workspace, conversation, message и locator свежим данным текущей ветки. Оригиналы с `file_id` разрешаются существующим файловым маршрутом. Для sandbox-файлов применяется GET `/backend-api/conversation/{conversation_id}/interpreter/download` с `message_id`, `sandbox_path` и `download_intent=true`; результатом должен быть `download_url`. Ответ 403/404/410 или отсутствие URL даёт явный недоступный результат, без поиска по соседним сообщениям, другим workspace или совпадающим именам.

Контракт sandbox-маршрута проверен по первичной реализации `get_response_file_url` в `lanqian528/chat2api`, файлу `chatgpt/ChatService.py`, и авторскому описанию наблюдаемого поведения в `Ma-XX-oN/DownloadConversation`, issue 78. Это внутренний веб-маршрут, а не обещание стабильности публичного API. Первичные материалы: https://github.com/lanqian528/chat2api/blob/main/chatgpt/ChatService.py ; https://github.com/Ma-XX-oN/DownloadConversation/issues/78 .
