# Chat Archive Exporter v0.1.9 rev.1 — Selective conversation export

Дата: 2026-11-25. Основа: v0.1.8 rev.1.

## Управление

Кнопка **Download MD** в popup и side panel теперь состоит из основного действия и стрелки меню. Меню содержит **All / Question / Answers / Thinking**, затем **Uploaded files / Generated files**.

- **All** включает все пять категорий; частичный выбор отображается смешанным состоянием.
- **Complete conversation** задаёт охват сообщений независимо от категорий. По умолчанию включены All и Complete conversation.
- При Complete conversation включённом основная кнопка сразу принимает экспорт текущего разговора.
- При отключённом флаге основная кнопка открывает селектор в существующей side panel. В нём доступны All / Questions / Answers / None / Invert, индивидуальные checkbox, счётчик и раскрытие текста.
- Доступный Thinking входит в соответствующий ответ, но его содержимое можно исключить отдельно.
- Настройки категорий и Complete conversation общие для всех экземпляров расширения в одном браузерном профиле. Они сохраняются после закрытия popup и перезапуска браузера.
- Конкретные message IDs привязаны к workspace, conversation, branch и вкладке. Они не переносятся в другой разговор.
- Полностью пустой выбор не запускает экспорт.

На страницу ChatGPT новая кнопка экспорта не добавляется. Удалён оставшийся старый элемент ↓MD. Необязательный ранее существовавший monitoring widget сохраняется.

## Содержимое результата

При отсутствии файлов, попавших под выбор, результат — обычный Markdown. Если включены ссылки на оригиналы выбранных сообщений, результат — ZIP:

- Markdown в корне;
- attachments/Uploaded и attachments/Generated с полученными оригиналами;
- export-report.json со статусом каждого файла.

Допускается экспорт только файлов: текст вопроса, ответа и Thinking можно отключить. Файлы из невыбранных сообщений не запрашиваются. Один физический file ID скачивается один раз; совпадающее имя само по себе не считается совпадением файлов.

Поддержаны ссылки с file ID и генерируемые файлы с sandbox-путём /mnt/data/. Перед получением оригинала проверяются workspace, разговор, сообщение и наличие именно этого файла в текущей ветке. Истёкшая sandbox-сессия, недоступный файл или отсутствие достоверного locator отражаются в отчёте и Markdown. Успешная локальная ссылка создаётся только на фактически сохранённые байты.

Лимиты пакета: 25 MiB на файл, 100 MiB полученных оригиналов за задание, 128 MiB временного staging и 12 MiB снимка/Markdown разговора. Превышение лимита файла отражается отдельным статусом; остальные допустимые файлы обрабатываются.

YAML содержит scope выбора, категории, IDs выбранных сообщений и ветку. Это позволяет отличить документ с выборочным содержимым от полного архива. Временный внутренний снимок разговора в выгрузку не входит.

## Фоновая обработка и целостность

- Принятый выбор фиксируется в задании. Последующие изменения общих checkbox его не меняют.
- Закрытие popup/панели не останавливает принятое задание.
- После перезапуска worker используются проверенные подготовленные байты. Повторный запрос уже сохранённого оригинала не нужен.
- Снимок, Markdown и оригиналы проверяются по SHA-256. Повреждённые данные не выдаются как успешная выгрузка.
- Stop прекращает новые запросы и при наличии подготовленного содержимого создаёт явно отмеченный частичный результат.
- Отмена браузерного сохранения сохраняет поведение v0.1.8: completed_not_saved без утверждения, что файл сохранён.
- Недоступный конкретный файл даёт предупреждение; auth/rate-limit/потеря исходного workspace переводят задание в ожидание.
- Устаревшая ветка требует повторного открытия селектора.

Настройки выборочного экспорта применяются к Download MD. Save to Vault, групповые архивы и background monitoring сохраняют полный формат и существующие пути. Разрешения расширения не расширены.

## Проверки и ограничения

70/70 Node test suites прошли. Интеграционные тесты используют настоящие Blob и ZIP с проверкой CRC/содержимого, но подменяют provider/browser API. Статически проверены JS, HTML-ссылки на модули и Python-тесты.

Новый интерактивный UI-тест подготовлен, но не выполнен: доступного локального Chromium нет; загрузка браузера получила HTTP 403, а cloud browser не видит локальный сервер. Реальные Chrome/Edge, authenticated ChatGPT endpoints и нативные Save-диалоги новой версии в этой сессии не проверялись.

См. TEST_REPORT_v0.1.9-rev1.md и UAT_v0.1.9-rev1.md. Тонкие настройки, рассмотренные по Exporter v6.13.2, внесены в TODO_v0.1.9.md.

## Обновление

Распаковать install ZIP в ту же папку unpacked-расширения, заменить файлы, нажать Reload на странице расширений и обновить вкладку ChatGPT. Удалять расширение, очищать IndexedDB или заново выбирать исправный Vault не требуется.

Эта сборка предоставлена как test build. Публикация GitHub Release в этом этапе не выполнялась.
