- Correctly authorize extension Settings tabs; separate workspace verification, controller availability and Vault access. Improve cold-start reconnection, deadlines and network recovery.

- Coalesce hung permission checks, back off failed probes, record per-context permission errors, and verify diagnostic download completion; provide Copy diagnostics and manual text fallback.
- Cooperative shared-local-Vault writer claims, protection against stale Library commits and older chat revisions.
- Required-action button styling, popup-to-side-panel Vault selection and truthful unknown states.

## Validation and limitations

74 Node regression suites passed for the rev.8 runtime; the maintainer reported no issues during subsequent practical testing. Exhaustive native Chrome/Edge concurrency tests were not independently performed. See UAT_v0.1.9-rev8.md.

All simultaneous writers must support the same cooperative guard and see the same coherent local filesystem. Older versions, independent cloud replicas and uncooperative writers are not covered. Never automatically steal a stale writer claim. Stop all writers before manually clearing stale `writer-*.lock` markers in `ChatGPT/.chat-archive/writers/`. Preserve the archive indexes.

The extension uses unofficial ChatGPT web endpoints. Availability and completeness vary with account, service changes and permissions. Native Space Pages/Sites and account/project Memory remain outside the archive scope. Use only where authorized by applicable terms and workspace policy.

Future v0.2 work remains separate. This is a beta, not a guarantee of complete or conflict-free backup in every environment.
