# Chat Archive Exporter v0.1.9 Beta 2

Functional public beta based on v0.1.9 rev.5. Includes all Beta 1 features: local Markdown/ZIP exports, selective message and content export, Library and image originals where available, workspace-scoped Vault archives, and opt-in background updates.

## Since Beta 1

- Indeterminate loading indicator and debounced same-workspace refresh of the current-chat message selector; stale replies cannot replace the selected chat.
- Full-height scrollable message selector with visible bottom actions.
- Monitor-only widget with short/expanded logs, no minimized mode or quick download/refresh buttons; Settings opens the Side Panel.
- Native tooltips and more compact controls; Files shortcut selects message rows containing enabled original-file references.
- Privacy policy and separate store packaging. No changes to archive engines, permissions or Vault paths.

## Install and known limits

Use the normal install ZIP for unpacked installation. Replace the existing unpacked extension files and reload it, without clearing its storage or Vault. The `-webstore.zip` asset is intended for the first Chrome Web Store upload, not a second installation alongside the unpacked copy. Store availability is not implied by this release.

71 Node regression suites pass. Chromium fixture checks were completed for rev.5. Authenticated API behavior, native permission and browser lifecycle details may vary. Some originals can be unavailable, and native Spaces/Pages/Sites and Memory are outside the archive scope. Individual attachment checkboxes remain planned.

This is an independent beta, not an official OpenAI product. It relies on undocumented ChatGPT web endpoints. Review applicable terms and workspace policies before use; the individual ChatGPT terms restrict automated or programmatic extraction. No endorsement or approval by OpenAI or the Chrome Web Store is claimed.
