# Chat Archive Exporter v0.1.9 Beta 1

This pre-release packages the tested v0.1.9 rev.3 build, including the v0.1.8 technical maintenance work on top of the v0.1.7 UX/UI. The extension manifest version remains 0.1.9; version_name identifies rev.3.

## Changes since v0.1.7 Beta 1

- Verified-copy deduplication for Library and Project Sources: a source association alone no longer blocks Library export. Existing copies are checked against file identity, size and SHA-256.
- Deterministic filename aliases for names rejected by Chromium, preserving original names in the index; safe recovery of Source writes interrupted before index commit.
- More complete file registry with Source-only references and evidence-backed conversation/message placements. New Project Source links are recorded during incremental Library checks even without new Library files.
- Selective current-chat export: persisted split-button content categories (Question, Answers, available Thinking, Uploaded files, Generated files), independent Complete conversation option and compact message selection.
- Text-only selection produces Markdown; selection with eligible originals produces a ZIP with Markdown, obtainable originals and an export report. Generated image-only outputs are recognized on the active conversation branch, with visible filenames when available. Unavailable originals are explicitly reported.
- Compact single-line rows with indented answers, real answer previews, ZIP/MD-aware download labels and concise tooltips. Full Vault and batch archives retain their existing behavior.

## Installation

Download the install ZIP, extract it and load the folder as an unpacked extension in Chrome or Edge. For an existing installation, replace files in the same unpacked directory, click Reload on the extensions page, and refresh ChatGPT. Preserve extension storage and Vault contents. No additional Chrome or host permissions and no Vault format migration.

## Validation and limits

71 Node regression suites passed locally. The rev.3 report records focused Chromium selector tests; authenticated image retrieval, full cross-surface behavior and native Chrome/Edge lifecycle tests are not exhaustively verified. Internal provider routes may change or reject individual originals. No hidden reasoning reconstruction, no account or project Memory export.

Individual attachment checkboxes and advanced Markdown metadata/filename settings remain in TODO_v0.1.9.md. See RELEASE_NOTES_v0.1.8-rev1.md, RELEASE_NOTES_v0.1.9-rev3.md and TEST_REPORT_v0.1.9-rev3.md.
