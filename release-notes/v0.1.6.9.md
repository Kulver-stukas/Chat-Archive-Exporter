# Chat Archive Exporter v0.1.6.9 (pre-release)

Initial public source release of the ChatGPT archive technology demonstrator. **Testing build, not production-ready.**

## Changes

- Read-only inventory of scheduled, paused, and completed ChatGPT automations for the verified active account, with schedule metadata and full user-authored prompts where available.
- Initial Vault export now captures current-scope configuration even for a selected chat or an empty Project.
- Exported chat metadata now tracks archived status, Project membership, titles, and available GPT labels without renaming existing Vault files.
- Background monitoring remains explicitly opt-in; incomplete API responses do not erase prior verified configuration.
- No new Chrome permissions. Account/Project Memory, sibling workspaces, and temporary chats remain out of scope.

## Install

Download the extension ZIP, extract it, then choose **Load unpacked** at `chrome://extensions` with Developer mode enabled. Select the extracted `chat-archive-exporter` directory. Existing users can update unpacked files in place and reload the extension.

## Known limitations

This version relies on undocumented ChatGPT endpoints. Native browser acceptance testing is ongoing. Library, Space, and Images inventories are planned for v0.1.6.10; production UI work is planned for v0.1.7.
