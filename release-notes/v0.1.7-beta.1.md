# Chat Archive Exporter v0.1.7 Beta 1 — rev.5

**Beta release, 21 November 2026.** This release completes the v0.1.7 UX/UI development stage. The tested extension is rev.5; the `manifest.json` displays the Beta milestone.

## User-facing changes

- **Popup-first** design: Export, Activity, Settings and a separate low-frequency **Tools** view with Vault reconnect, catalog JSON, workspace snapshot and diagnostics.
- **Side Panel on demand** for selecting chats and Library/Images originals, using filters, grouped checkbox lists and explicit actions. It can close after an export is accepted; jobs continue independently.
- **Monitoring widget** on the ChatGPT page, optional and draggable; compact status, expanded logs and automatic reconnection after MV3 worker idle/suspend.
- **Toolbar status badge** on a floppy-disk icon and consistent status presentation.
- **Instant cached chat list** when a verified workspace-scoped cached list is available; API refresh follows separately. A pending browser download no longer hides the chat list.
- **User-canceled browser Save** ends as `completed_not_saved` rather than `download_failed`: the prepared payload is cleared and another manual export can be started. Applies only to Markdown/ZIP browser downloads, never Vault operations.

## Archival invariants

- Continues the v0.1.6.11 rev.1 underlying Vault structure, workspace/account isolation, existing incremental chat and Library monitors, explicit manual exports, failure diagnostics, and restricted Project Sources behavior.
- One narrow approved maintenance exception: `lib/manual-jobs.js` implements the user-canceled browser-save transition. No other archive-core behavior is intentionally changed.
- No new Chrome permissions, no automatic export of Memory, temporary chats or native Pages/Sites, no silent migration.

## Known limitations / next milestone

- Library files that also appear as Project Sources may be excluded from standalone Library download even when their original is not yet archived as a Source. Fix must check actual archive evidence, not merely source membership.
- Some Project Source names rejected by File System Access (`getFileHandle: Name is not allowed`) need safe filename mapping with original-name metadata.
- Selective per-Prompt / Thinking / Response export is not implemented: whole-chat selection remains the functional unit.
- Native Space Pages/Sites, their nested structure and page automations are outside v0.1.7.
- Browser download errors, file availability and ChatGPT API responses depend on the account and Chrome version. The extension cannot guarantee successful recovery of unavailable originals.

## Verification

- **57/57 Node.js test suites** passed on the rev.5 source; previous synthetic UI checks were reported in the bundled `TEST_REPORT_v0.1.7-rev5.md`.
- Additional owner verification: several days of use without significant issues (not an exhaustive compatibility certification).
- Install by replacing the files in the *same unpacked extension directory* and clicking **Reload** at `chrome://extensions`. Do not uninstall or clear extension storage to keep existing Vault handles/settings.

This is a GitHub **pre-release** (Beta), not a Chrome Web Store deployment.
