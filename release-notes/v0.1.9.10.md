# v0.1.9.10 — shared Workspace views (beta candidate)

Backport of issue #8 on top of writer recovery (#6).

- Load the saved workspace-validated Library inventory from Vault on connection and opening Files. Show saved rows before any API check; if older than five minutes, request one incremental metadata check on opening Files. No automatic initial inventory, original downloads or monitoring opt-in.
- Share terminal manual export and significant Library activity receipts in .activity-manual.json and .activity-library.json. Only timestamps, operation type, status and counts; no raw logs, download IDs, paths, permissions or queues. Browser download completion is historical, in its originating browser. Active/resumable jobs remain local.
- Older inventory/report metadata supplies Library history. To backfill a prior manual export, open the originating upgraded profile with its retained history and connected Vault.
- Passive reads do not acquire writer claims. Writes obey the shared guard and reject stale receipts. No new permissions or existing index migration.

Native authorized Chrome/Edge UAT required before release.
